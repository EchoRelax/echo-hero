# CrazyGames SDK v3

Интеграция находится в `src/platform/CrazyGames.ts`. Официальный SDK загружается из `https://sdk.crazygames.com/crazygames-sdk-v3.js`. До создания игры ожидается `SDK.init()` и готовность Data-модуля.

## Сборки

- `npm run build` — автономная сборка в `dist`, без загрузки SDK из сети.
- `npm run dev:crazygames` — разработка с настоящим SDK на localhost.
- `npm run build:crazygames` — SDK-сборка в `dist-crazygames`.
- `npm run preview:crazygames` — локальный просмотр SDK-сборки.
- `./tools/package_crazygames.ps1` — создание ZIP для Developer Portal в `releases`.

В архиве CrazyGames `index.html` находится непосредственно в корне. Windows-запускатель из playtest-архива в него не входит. Пути к игровым ресурсам в собранном HTML/CSS/JS относительные.

## Загрузка в Developer Portal

1. Создать игру или открыть её черновик в https://developer.crazygames.com/.
2. Загрузить `EchoHunt-CrazyGames-*.zip` как HTML5-сборку.
3. В настройке сохранений выбрать **Yes, using the Data Module from the CrazyGames SDK**. Это обязательно для данной сборки.
4. Открыть Preview и проверить сохранение/возврат в игру на площадке. Локальный режим не подтверждает реальную синхронизацию аккаунта между устройствами.

Рекламные показы пока не размещены. Эта сборка подключает жизненный цикл игры, Data, настройки звука и события прохождения.

## Жизненный цикл

После инициализации перед загрузкой моделей вызывается `loadingStart()`. `loadingStop()` вызывается после создания мира и UI, перед первым `gameplayStart()`.

Меню, пауза, смерть и победа переводят SDK в `gameplayStop()`. Продолжение и возрождение вызывают `gameplayStart()`. Повторные события одного состояния отсекаются. При потере фокуса локальная симуляция, ввод, звук и таймер останавливаются отдельно: события фокуса площадка учитывает сама.

Победы над боссами вызывают `happytime()`. Доля побеждённых боссов передаётся через `reportGameCompletedPercentage()` при загрузке и победах: 0/33/67/100.

## Сохранения и звук

На SDK-площадке прогресс и настройки используют только `SDK.data`. Если сохранения ещё нет, прежние ключи `echo-hunt-progress` и `echo-hunt-settings` переносятся из localStorage один раз. Существующие данные площадки имеют приоритет. Маркер миграции сохраняется после сброса игры, чтобы старое локальное сохранение не восстановилось повторно.

Ошибка инициализации или первоначального чтения Data останавливает запуск до создания персонажа. Ошибка записи показывает недоступность сохранения; переключения на устаревшую локальную копию нет. При входе в аккаунт запись старого гостевого сеанса блокируется до автоматической перезагрузки SDK.

`game.settings.muteAudio` и его listener временно выключают звук независимо от пользовательского переключателя. Настройка игрока при этом не перезаписывается. Первый язык выбирается по locale площадки, если игрок ещё не сохранил выбор RU/EN.

## Проверка

`node tools/check_crazygames.mjs` проверяет адаптер через изолированную подмену SDK: порядок событий, приоритет данных, миграцию, сброс, ошибки хранения, звук, смену аккаунта и отключённую среду. Выполнялась также проверка настоящего CDN SDK в локальной production-сборке. Preview и облачная синхронизация на реальных аккаунтах остаются отдельным этапом проверки на площадке.
