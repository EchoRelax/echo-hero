ECHO HUNT — сборка для тестирования

ЗАПУСК НА WINDOWS 10/11
1. Полностью распакуйте ZIP-архив в отдельную папку.
2. Запустите Play.cmd двойным щелчком.
3. Игра откроется в браузере по адресу http://127.0.0.1:8787.
   Если браузер не открылся автоматически, откройте этот адрес вручную.
4. Оставляйте окно запуска открытым во время игры. Закройте его после игры.

Node.js, Python и Blender для запуска не нужны. Игра работает локально.
Не запускайте index.html двойным щелчком: модели и звуки требуют локального сервера.
Если порт 8787 занят предыдущим запуском, закройте его окно и запустите заново.

УПРАВЛЕНИЕ
WASD или стрелки — движение. Удары по врагам выполняются автоматически.
Esc — пауза. Настройки доступны через интерфейс игры.
Монеты сначала попадают в груз; вернитесь на базу, чтобы сдать их.
На базе можно восстановить здоровье.
Таланты открываются каждые 5 уровней в меню улучшений.
Язык RU/EN, звук и графика меняются в настройках.

ТАЙМЕР ДО ПЕРВОГО БОССА
Таймер слева считает активную игру и сохраняет время вместе с прогрессом.
В меню, на паузе и после смерти отсчёт приостановлен.
После победы над первым боссом результат фиксируется.
Для чистого замера начните новую игру через сброс прогресса в настройках.
Сброс удаляет прежнее сохранение в этом браузере на этом адресе.
В старых сохранениях прежнее время не записывалось.

ПРОГРЕСС
Сохраняется в этом браузере на этом компьютере. У каждого игрока своё сохранение.
Новый браузер начинает с нового прогресса. Если на этом адресе уже играли,
сохранение может загрузиться; его можно сбросить в настройках игры.

ОБРАТНАЯ СВЯЗЬ
При ошибке отправьте автору скриншот или видео, описание действий перед ошибкой,
идентификатор сборки из BUILD.txt, разрешение экрана, название браузера и модель компьютера. Для баланса полезно указать время игры,
уровень героя, выбранные таланты и лагерь, до которого удалось дойти.
Для первого босса запишите итоговое время таймера.

ENGLISH QUICK START
Extract the entire ZIP, then double-click Play.cmd.
Keep the launcher window open while playing. No Node.js or Python installation is needed.
Change the language in Settings > Language > English (EN).
For a fresh timing run, reset progress in Settings > New adventure.
Include BUILD.txt information when reporting bugs or balance feedback.

ДЛЯ ВЕБ-ХОСТИНГА
Содержимое папки game можно разместить в корне статического веб-хостинга с HTTPS.
Тогда друзьям будет достаточно ссылки; Windows-запускатель не понадобится.
